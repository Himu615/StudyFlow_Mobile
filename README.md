# StudyFlow Mobile

React Native / Expo mobile client for StudyFlow.

## Local setup

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env`.
3. Set `EXPO_PUBLIC_API_URL` to the deployed StudyFlow API URL.
4. Start Expo with `npm start`.

The mobile app uses the existing StudyFlow API. The web and API repositories are not modified by this project.
